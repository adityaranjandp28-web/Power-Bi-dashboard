# Power BI Dashboard — At-Risk Intelligence

An interactive, Power BI-style dashboard prototype for identifying students and employees who may need additional support.

## Files
- `index.html` — Interactive dashboard. Open it in a modern browser.
- `Power-BI-Dashboard.pptx` — Presentation exported from the supplied Keynote file.

## Features
- Education and Corporate / HR modes
- Overview, people directory, risk analysis, performance, attendance, insights, reports, and settings
- Dark/light theme toggle
- CSV upload and data-driven dashboard views
- Search, filters, sortable tables, individual profiles, and CSV export

## Run locally
Open `index.html` in a modern browser. The page loads Chart.js and Papa Parse from CDNs, so an internet connection is required for those libraries.

## Important note
The included sample dataset is synthetic. Risk scores use a demonstration weighted heuristic and are not a validated predictive model. Do not use demo scores to make real academic, employment, or other high-impact decisions.
